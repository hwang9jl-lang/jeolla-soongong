# 2026-11-25 학생 앱 아이콘 교체

학생용 앱 아이콘을 사용자가 제공한 공부하는 강아지 이미지를 기반으로 교체했습니다. 바깥 테두리와 여백을 없앤 정사각형 이미지이며, 192×192 및 512×512 PNG입니다.

## 반영 범위

- `icon-192.png`, `icon-512.png`
- `manifest.json`의 아이콘 주소에 `?v=20261125` 추가
- `apply.html`, `index.html`, `rank.html`, `seat.html`의 Apple 홈 화면 아이콘 주소에 같은 버전 추가
- 관리자 아이콘, 공부 기록 처리 코드, Firebase 규칙은 기존 파일과 동일합니다.
- 앱 이름, 시작 주소, manifest 연결 주소는 유지합니다.

## 배포 파일

[soongong-deploy.zip](../releases/2026-11-25-icons/soongong-deploy.zip) — 1,696,460바이트

기존 Cloudflare Pages 프로젝트에 이 ZIP을 직접 업로드합니다. `release-files.json`에 있는 22개 파일을 ZIP 최상위에 담았습니다. GitHub 저장소에 반영한 것이며 Cloudflare 운영 사이트에 자동 배포한 것은 아닙니다.

## 검증

- PNG 서명, 청크 CRC, zlib 체크섬, 실제 픽셀 크기 검증
- 192×192 및 512×512 변환 전후 PNG 왕복 디코딩과 픽셀 일치, 불투명 배경 확인
- manifest JSON과 아이콘 경로 및 크기 일치 확인
- ZIP의 22개 고유 파일, 로컬/중앙 디렉터리 헤더, CRC, 저장 데이터 일치 확인
- 변경한 HTML은 아이콘 주소 한 곳만 변경했으며 모든 script 블록은 이전과 동일
- 나머지 배포 파일 15개는 기준 커밋 `8c7d8708b76cbe1a4a8574d1fa48c48c4fbd2664`와 바이트 단위 일치
- 이번 작업에서는 실행 환경을 사용할 수 없어 기존 Node/브라우저 동작 시험을 다시 실행하지 않았습니다. 위 검증은 이미지와 배포 패키지에 대한 검증입니다.

패키지는 실행 환경 대신 순수 JavaScript로 구성했으며 ZIP은 저장 방식(무압축)을 사용합니다. 기존 `scripts/package_release.py`로 다시 패키징하면 압축 방식 차이 때문에 ZIP 자체의 바이트는 달라질 수 있지만 포함된 웹 파일은 같습니다.

## 휴대폰 확인

배포 후 사이트를 새로고침합니다. 기존 홈 화면 아이콘이 계속 보이면 홈 화면의 바로가기를 삭제하고 사이트에서 다시 추가합니다. 브라우저에 따라 기존 설치 아이콘의 자동 갱신에는 시간이 걸릴 수 있습니다.
