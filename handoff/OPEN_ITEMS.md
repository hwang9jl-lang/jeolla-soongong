# 문제 번호별 처리 상태와 남은 사항

아래 번호는 이 채팅에서 사용자가 검토한 번호를 유지합니다. '수정'은 소스 수정 및 가상 시험 범위의 결과이며 운영 무결점 보증이 아닙니다.

| 번호 | 문제 | 상태 |
|---|---|---|
| 1 | 중복 종료 가산 | 수정: 기록 상태 조건부 트랜잭션, 기록에서 합계 계산 |
| 2 | 자정 후 다음 날 저장 | 수정: 시작 날짜 고정, 해당 날짜 마감 적용 |
| 3 | 진행 중 QR의 PIN 생략 | 사용자 선택으로 유지. 신뢰 기반 운영 |
| 4 | 관리자 인증 없음/공개 DB | 사용자 선택으로 유지. 공개 읽기·쓰기와 평문 PIN 조회 위험이 실제 규칙에서 확인됨 |
| 5 | 무효·교사 인정과 합계 불일치 | 수정: 하루 전체 무효와 기록 기반 합계 |
| 6 | 22시 재개/자동 마감 누락 | 수정: 상태 변경 검증, 열린 관리자 화면의 주기적 정리. 서버 스케줄러는 없음 |
| 7 | 기기 시계/시간대 영향 | 수정: Firebase 시각 보정 + 단조 시계 + KST. 서버 최종 검증은 없음 |
| 8 | 화면/인쇄 좌석 배열 불일치 | 사용자 요청으로 보류 |
| 9 | 오늘 순공에 누적 표시 | 수정: 오늘 완료분+진행 구간 |
| 10 | 재시작 중 오전분 집계 제외 | 수정: prevSec 인정 및 실시간 집계 |
| 11 | 같은 학번 동시 신청 덮어쓰기 | 수정: 학번별 최초 저장만 허용. 순번 예약 공백은 허용 |
| 12 | 동시 좌석 배정 충돌 | 사용자 1인 운영 방침으로 보류. 여러 탭 사용 시에도 발생 가능 |
| 13 | 코드 동시 생성 충돌 | 사용자 1인 운영 방침으로 보류 |
| 14 | 현재 명단 변화로 과거 조회 누락 | 수정: 비활성 보존, 당시 명단/좌석, 과거 참여자 조회. 최초 이력 이전 결석자 복원 불가 |
| 15 | QR 페이지 불필요한 Firebase 스크립트 | 제거 |
| 16 | 오류 안내/중복 클릭 부족 | 보완: 연결/저장 오류 안내와 동작 잠금. 모든 네트워크 경합을 서버에서 통제하는 구조는 아님 |

후속 수정: 신청 이력 화면의 참여 확정/좌석 표시, 임시·확정 서버 타임스탬프 불일치로 일시정지를 거부하던 경로 수정.

## 다음 담당자의 우선 확인

1. 실제 운영 배포와 최신 소스/규칙의 일치 여부, 운영 Firebase 저장 권한을 확인합니다.
2. 실제 기기/네트워크 복귀 시험을 완료합니다. 현재 로그는 가상 DB 검증 증거입니다.
3. 관리자 인증과 서버 권한 분리가 필요하면 별도 설계합니다. 현재 `.write: true` 경로에서는 클라이언트 중복 방지 코드를 우회한 직접 쓰기가 가능하며, 코드의 검증을 보안 경계로 간주하면 안 됩니다.
4. 미래에 학생 수/기간이 늘면 `records` 전체 구독/조회 비용을 검토합니다. 현재는 소규모 운영 전제입니다.
5. 기존 점검의 추가 개선 사항(이름/학번 입력 검증, CSV 큰따옴표·수식 문자 처리 등)은 이 인수인계에서 전면 재검토/수정하지 않았습니다.

Firebase Emulator 테스트와 자동 CI는 아직 구성하지 않았습니다. 기존 테스트의 가상 DB는 원자적인 결과를 모형화하지만 실제 규칙, SDK 캐시, 서버 지연을 완전하게 검증하지 못합니다.
