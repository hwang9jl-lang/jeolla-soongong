## 재실행

Node 시험에는 추가 패키지가 필요 없습니다.

```sh
node tests/records.test.cjs
```

브라우저 시험에는 Playwright가 필요합니다. 별도 개발 환경에서 아래처럼 설치할 수 있습니다. Node 24 계열을 권합니다.

```sh
npm install --no-save --package-lock=false playwright@1.62.1
npx playwright install chromium
node tests/browser-smoke.cjs
```

환경에 /usr/bin/chromium이 있으면 이를 사용하고, 그 외에는 Playwright 설치 브라우저를 사용합니다. 필요하면 CHROMIUM_PATH를 지정합니다. 컨테이너 샌드박스가 Chromium의 소켓 생성을 막으면 허용된 실행 환경에서 재실행합니다. 시험은 모든 HTTP 요청을 로컬 파일/가상 응답으로 가로채므로 실제 운영 DB를 읽거나 쓰지 않습니다.

## 회귀 시험의 핵심

중복 종료/시작, 오래된 탭에서 다른 세션 변경 차단, 자정 이후 원래 날짜 무효 처리, 오전분 유지와 하루 전체 무효, 휴식 제외, 저장 실패 후 재시도, 최신 기록을 과거 스냅샷으로 무효 처리하지 않기, 랭킹 실시간 반영, 교사 인정 중복 방지, 동시 신청과 기존 정보 보존, 비활성/삭제된 학생의 기록 복원, 과거 좌석/결석자/명단 미확인 구분, 기기 시계 변경/연결 끊김/시각 미준비 차단을 검사합니다.

특히 마지막 일시정지 수정은 완료 응답의 시각과 DB 확정 시각을 37ms 다르게 만들어, 새로고침 없이 시작→정지→재개→정지→종료가 되는지 검사합니다. 이 모형은 해당 오류 경로를 재현하지만 Firebase SDK의 모든 캐시/네트워크 동작을 재현하지는 않습니다.
